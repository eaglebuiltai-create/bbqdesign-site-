30" Outdoor Warming Drawer. Always confirm with the manufacturer's spec sheet before cutting.

Plan a 30-inch-deep island. This cutout is 24 3/16" deep; anything past about 23 1/2" leaves no workable structure in a 24-inch island.

  • Category: warming drawer
  • Fuel / power: Electric: 120VAC, 15A GFI
  • Flange: 30" W × 16" H (DCS WD1-30 warming drawer install guide 590833C, Fig. 03A: front 30" x 16")
  • Overall size: check spec sheet
  • Source: Proud install per DCS WD1-30 install guide; depth is the minimum cabinet depth. Flush install: 30-3/16" W × 16-3/16" H, 26-3/16" min. depth. Same cutout: WD1-30-SSOD.
